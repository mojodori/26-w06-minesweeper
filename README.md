# 💣 지뢰찾기

## 게임 소개

브라우저에서 바로 플레이할 수 있는 클래식 지뢰찾기 게임 (HTML / CSS / JavaScript)

- 격자 안에 숨겨진 지뢰를 피해, 지뢰가 없는 모든 칸을 열면 승리 / 지뢰를 열면 패배
- 열린 칸의 숫자는 주변 8칸에 있는 지뢰 개수
- 난이도 3단계
  - 초급: 9 x 9, 지뢰 10개
  - 중급: 16 x 16, 지뢰 40개
  - 고급: 30 x 16, 지뢰 99개
- 조작
  - 좌클릭: 칸 열기 (주변 지뢰가 0개면 인접 칸 연쇄 오픈)
  - 우클릭: 깃발 설치 / 해제
  - 열린 숫자 칸 클릭: 주변 깃발 수가 숫자와 같으면 나머지 칸 한 번에 오픈 (chord)
- 첫 클릭한 칸과 주변 8칸에는 지뢰가 배치되지 않음
- 타이머, 남은 지뢰 수, 재시작 버튼 제공

## 어떻게 만들었나요

VS Code의 GitHub Copilot Chat(Agent 모드)을 사용해 PRD → Plan → Agent 순서로 구현

1. PRD 작성
   - 템플릿(목표 / 핵심 규칙 / 화면 요소 / 제외 기능)에 맞춰 게임 요구사항 정리
   - 격자 크기와 지뢰 수, 좌·우클릭 동작, 승리·패배 조건, 첫 클릭 안전 규칙을 구체적인 수치와 조건으로 명시
   - 물음표 표시, 최고 기록 저장, 모바일 터치 지원은 이번 범위에서 제외
2. Plan 확인·보완
   - PRD를 Copilot에 전달해 구현 계획을 먼저 받고, 규칙 누락 여부를 확인
3. Agent 구현
   - Agent 모드로 index.html, styles.css, script.js 생성
   - 브라우저에서 직접 플레이하며 동작 확인 후 추가 요청으로 보완
     - 참고 이미지를 첨부해 전통적인 지뢰찾기 디자인 반영 요청
     - 패배 처리 보완

## freeform 버전과 비교했을 때

freeform 브랜치는 PRD 없이 "지뢰찾기 게임 만들어줘" 한 줄 요청으로, prd 브랜치는 작성한 PRD를 전달해 구현

| 항목 | freeform 버전 | prd 버전 |
| --- | --- | --- |
| 첫 클릭 | 첫 클릭에 지뢰가 터질 수 있음 | 첫 클릭 칸과 주변 8칸 안전 보장 |
| 난이도 | 고정 크기 1개 | 초급 / 중급 / 고급 선택 |
| chord | 없음 | 숫자 칸 클릭으로 주변 일괄 오픈 |
| 우클릭 | 브라우저 메뉴가 함께 뜨는 경우 있음 | 게임판에서 기본 메뉴 차단 |
| 남은 지뢰 수 | 미표시 또는 고정값 | 깃발 수에 따라 실시간 갱신 |
| 패배 처리 | 알림창만 표시 | 전체 지뢰 공개, 밟은 지뢰 강조, 잘못된 깃발 X 표시 |
| 디자인 | 기본 버튼 형태의 단순한 격자 | 고전 지뢰찾기 스타일 |

- freeform 버전
  - 빠르게 동작하는 결과물은 나왔지만, 세부 규칙을 AI가 임의로 정해서 기대한 동작과 다른 부분이 많았음
  - 원하는 기능을 추가하려면 매번 다시 설명해야 했음
- prd 버전
  - 규칙과 범위를 미리 정해두어 요구사항이 구현에 그대로 반영됨
  - 만들지 않을 기능까지 명시해 불필요한 기능 없이 결과물이 일관됨
  - 이후 수정할 때도 PRD를 기준으로 요청할 수 있어 관리가 쉬움
- 최종 선택: 규칙 완성도와 플레이 경험이 더 좋고, 요구사항대로 동작하는지 검증할 기준이 있는 prd 버전을 최종본으로 선택

## 커스터마이징한 부분

- 디자인: 참고 이미지를 바탕으로 회색 입체 테두리, 숫자별 색상, 상단 카운터·타이머 패널 등 윈도우 고전 지뢰찾기 스타일 적용
- 난이도 선택(초급 / 중급 / 고급) 추가
- 코딩(chord) 기능 추가
- 첫 클릭 시 주변 8칸까지 지뢰가 없도록 안전 범위 확장
- 패배 처리 보완: 전체 지뢰 공개, 밟은 지뢰 빨간 배경 강조, 잘못 꽂은 깃발 X 표시
- 승리 시 남은 지뢰 칸에 깃발 자동 표시, 클리어 시간 메시지 출력
